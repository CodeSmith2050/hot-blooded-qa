# 热血问答 - 无偿献血人群问卷调研系统

## 1. 需求分析

### 1.1 项目背景
本系统旨在为无偿献血人群提供便捷的问卷调研服务，支持在手机端（包括微信环境）和电脑端流畅使用，实现问卷的创建、发布、填写和数据收集分析的全流程管理。

### 1.2 目标用户
| 用户角色 | 描述 | 核心需求 |
|---------|------|---------|
| 问卷管理员 | 无偿献血机构工作人员，负责创建和管理问卷 | 快速创建问卷、导入问卷模板、发布问卷、查看统计结果 |
| 问卷填写者 | 无偿献血者或潜在献血者 | 便捷填写问卷、支持微信打开、界面友好 |
| 数据分析人员 | 负责数据统计分析的工作人员 | 导出数据、生成报表、数据可视化 |

### 1.3 使用场景
1. **问卷创建场景**：管理员登录系统，通过可视化编辑器或导入模板创建问卷
2. **问卷发布场景**：生成问卷链接或二维码，分享到微信或其他渠道
3. **问卷填写场景**：用户在手机或电脑上访问问卷链接，填写并提交
4. **数据查看场景**：管理员查看问卷统计结果和详细数据

### 1.4 核心痛点
- 传统纸质问卷效率低、成本高、统计困难
- 现有在线问卷工具可能不支持微信环境或移动端适配不佳
- 缺乏针对无偿献血场景的专业问卷模板

##### 4.2.3.4 数据处理统计设计

**统计指标计算**

| 指标 | 计算方式 | 用途 |
|-----|---------|-----|
| 总填写数 | count(answers) | 问卷参与度 |
| 完成率 | count(completed) / count(total) * 100% | 问卷质量评估 |
| 平均填写时长 | avg(submitTime - startTime) | 用户体验分析 |
| 各选项占比 | count(option) / count(total) * 100% | 选项分布分析 |
| 评分平均分 | avg(rateValue) | 满意度评估 |
| 渠道来源分布 | count(source) group by source | 推广效果分析 |
| 设备类型分布 | count(deviceType) group by deviceType | 用户设备偏好 |
| 时间分布 | count(submitTime) group by date/hour | 填写时间规律 |
