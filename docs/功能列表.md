## 三、与 PRD 对照的差异分析

### 3.1 接口路径差异

PRD 7.2 节定义的接口与实际实现存在以下差异：

| PRD 定义 | 实际实现 | 差异说明 |
|---------|---------|---------|
| `POST /api/users/login` | `POST /api/auth/login` | 路径前缀改为 auth |
| `POST /api/answers` | `POST /api/answers/submit` | 子路径调整 |
| `GET /api/answers/:id` | `GET /api/answers/:questionnaireId/:answerId` | 改为双参数 |
| `GET /api/answers/export` | （未实现） | 缺失导出接口 |
| `GET /api/questionnaires/:id/publish` (GET) | `POST /api/questionnaires/:id/publish` | 改为 POST（更合理） |
| `GET /api/statistics/:id` | `GET /api/answers/statistics/:questionnaireId` | 路径与模块归属调整 |
| `GET /api/statistics/dashboard` | （未实现） | 缺失仪表盘接口 |
| `GET /api/statistics/export` | （未实现） | 缺失统计导出接口 |

### 3.2 数据模型差异

| PRD 字段 | 当前模型 | 差异说明 |
|---------|---------|---------|
| Answer.isCompleted | 未实现 | PRD 要求记录是否完整填写，用于完成率统计 |
| Answer.userId / anonymousId | 未实现 | PRD 要求区分登录用户/匿名用户 |
| Answer.ipAddress | 未实现 | PRD 要求脱敏存储 IP |
| statistics 表 | 未实现 | PRD 要求预计算统计结果表 |
| Question.logicJump | 未实现 | 逻辑跳转字段缺失 |
| User.role = admin/analyst/editor | 仅 admin/user | 角色体系简化 |

### 3.3 功能缺失汇总（按优先级排序）

**高优先级缺失（影响核心流程）：**
1. 数据导出（Excel/CSV） - 后端接口未实现

3. 题目级统计分布 - 后端聚合管道未实现
4. 防重复提交 - 前后端均未实现
5. 角色权限控制 - 仅二角色简化实现
6. 后端单元测试 - 框架已就绪但无用例

**中优先级缺失（影响体验与扩展性）：**
7. 进度保存/断点续填
8. 微信 JS-SDK 集成
9. 逻辑跳转功能

## 六、使用说明

1. **更新状态**：每完成一项功能，将对应行的状态字段由 ⬜/🟡 改为 ✅，并在"说明/验证依据"列填写代码位置或验证方式。
2. **新增功能**：若需求扩展，在对应模块下新增行，分配编号（模块前缀+三位数字）。
3. **进度计算**：完成率 = (✅数 + 0.5×🟡数) / 总功能数 × 100%，更新后同步刷新"一、总体进度概览"。
4. **里程碑同步**：每完成一个里程碑的关键交付物，更新"四、里程碑达成情况"。
